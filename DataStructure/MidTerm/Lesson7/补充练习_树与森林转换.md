# 补充练习 01 · 树、森林与二叉树的转换

> 配合 `学案07_树与二叉树.md` 第八节｜代码 `src/tree_forest.cpp`｜答案 `solution/tree_forest.cpp`｜实测 `log/tree_forest.txt`

这一节最容易“看懂图、写不出代码”，原因是它其实只做了一件事：**把「第一个孩子 + 下一个兄弟」这两个关系，分别塞进二叉树的左、右指针**。把这句话记牢，转换、遍历对应关系、森林串接都能自己推出来。

---

## 一、一句话记住转换规则

> 左指针装「第一个孩子」，右指针装「下一个兄弟」。

```
树结点                        二叉树结点
data | firstChild | nextSibling   →   data | left | right
```

于是：

| 树里的关系 | 转换后变成 |
|---|---|
| 结点 p 的第一个孩子 | p 的左子女 |
| 结点 p 的下一个兄弟 | p 的右子女 |
| p 的其余孩子 | 沿 p 的左子女的右链依次排列 |

注意：**右指针不是“第二个孩子”**，而是“兄弟”。第二个孩子是“第一个孩子的下一个兄弟”，所以在右链上。

---

## 二、手算一遍

树：

```
        A
      / | \
     B  C  D
    / \    |
   E   F   G
```

按“左孩子-右兄弟”逐点写：

1. A 的第一个孩子是 B → `A.left = B`；
2. B、C、D 互为兄弟 → `B.right = C`，`C.right = D`；
3. B 的第一个孩子是 E → `B.left = E`；
4. E、F 互为兄弟 → `E.right = F`；
5. D 的第一个孩子是 G → `D.left = G`；
6. 根 A 没有兄弟 → `A.right = NULL`（转换后二叉树根一定没有右子树）。

得到的二叉树：

```
        A
       /
      B
     / \
    E   C
     \   \
      F   D
         /
        G
```

> 旁注｜不要把它画成“每个结点最多两个孩子”的普通树。转换后的二叉树里，**C 是 B 的右子女**，表示“C 是 B 的兄弟”，不是“C 是 B 的孩子”。这是整节最反直觉的地方。

## 三、遍历为什么会对上

| 树/森林 | 对应二叉树 |
|---|---|
| 树的先根遍历 | 二叉树的前序遍历 |
| 树的后根遍历 | 二叉树的中序遍历 |
| 森林的先根遍历 | 二叉树的前序遍历 |
| 森林的后根遍历 | 二叉树的中序遍历 |

用上面的例子验证：

- 树先根：A → B → E → F → C → D → G，即 `ABEFCDG`；
- 树后根：E → F → B → C → G → D → A，即 `EFBCGDA`。

转换后二叉树：

- 前序：A B E F C D G = `ABEFCDG`（与树先根一致）；
- 中序：E F B C G D A = `EFBCGDA`（与树后根一致）。

**为什么后根对应中序**：后根是“先处理所有孩子，再处理根”。转换后，“孩子”变成了左子树，“根”在中间访问，顺序正好是「左—根」，也就是中序。

## 四、森林怎么接

森林 = 多棵互不相交的树。转换分两步：

1. 每棵树各自按“左孩子-右兄弟”转成二叉树；
2. 把第 2 棵树的根作为第 1 棵树根的**右子女**，第 3 棵作为第 2 棵的右子女，依次串下去。

```
森林：T1=A(B,C)   T2=D(E)   T3=F(G,H)

转换后：
        A
       / \
      B   D
       \  / \
        C E   F
             / \
            G   H
```

根 A 的右链是 A → D → F，正好对应三棵树的根。验证：

- 森林先根：A B C D E F G H = `ABCDEFGH`；
- 二叉树前序：A B C D E F G H = `ABCDEFGH`；
- 森林后根：B C A E D G H F = `BCAEDGHF`；
- 二叉树中序：B C A E D G H F = `BCAEDGHF`。

关键结论：**森林转成的二叉树，根结点没有左兄弟，但右子树装着“除第一棵树以外的所有结点”**。填空题常考这一句。

---

## 五、反向：二叉树怎么拆回森林

从二叉树的根开始，沿**右链**走：

- 根是第 1 棵树的根；
- 根的右子女是第 2 棵树的根；
- 再往右是第 3 棵……

每一棵树的内部仍然保持“左孩子-右兄弟”的表示。拆的时候，把当前根与它的右子女断开，就得到一棵独立的树。

代码里用一个只走 `left`、在子女层用 `right` 找兄弟的函数即可，不必真的修改指针：

```cpp
void printOneTree(BinNode *root) {
    if (!root) return;
    printf("%c", root->data);
    for (BinNode *c = root->left; c; c = c->right)
        printOneTree(c);
}
```

外层再沿 `root->right` 遍历每棵树的根。

## 七、易错点

1. **右指针装兄弟，不装第二个孩子**。第二个孩子在“第一个孩子的右链”上。
2. 树转成的二叉树，**根没有右子树**；森林转成的二叉树，根有右子树（右链是其他树）。
3. 树的先根对应二叉树**前序**，树的后根对应二叉树**中序**，不要记成“后根对后序”。
4. 层次遍历转换前后**不保持**同样的序列，别拿层序去做对应关系。
5. 反向拆分时，只沿根结点的右链拆；树内部的右指针仍然是兄弟，不能一起拆掉。

## 八、自测

**题 1** 树 `A(B(D,E),C(F))` 转成二叉树后，前序和中序分别是什么？

<details><summary>答案</summary>

前序 `ABDECF`，中序 `DEBFCA`。

树先根：A B D E C F；树后根：D E B F C A。转换后二叉树前序 = 树先根，中序 = 树后根。

</details>

**题 2** 一棵二叉树的前序是 `ABCDEF`、中序是 `BCAEDF`，它对应几棵树组成的森林？每棵树的根是谁？

<details><summary>答案</summary>

沿根 `A` 的右链拆：`A` 的右子女是 `D`，`D` 的右子女是 `F`（由中序 `BC A E D F` 与右链结构判断），所以是 3 棵树，根分别为 `A`、`D`、`F`。

</details>

**题 3** 为什么“树的先根遍历 = 二叉树的前序遍历”？

<details><summary>答案</summary>

先根是“根 → 第一个孩子 → 其余孩子”。转换后，第一个孩子是左子树，其余孩子通过右链挂在左子树上。二叉树前序是“根 → 左子树 → 右子树”，沿右链走正好依次访问其余孩子，所以顺序完全一致。

</details>

## 九、一句话带走

左指针管“往下”，右指针管“往右”；树的多叉关系，被压成了二叉树的左链和右链。

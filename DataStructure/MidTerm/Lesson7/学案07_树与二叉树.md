# 学案 07 · 树与二叉树

对应课件 `课件/chapter-6-1-full.pptx`（86 页）｜教材：殷人昆《数据结构》第 3 版，第 6 章前半

从线性结构跨到非线性结构，这一讲是分水岭。树的结点有一个前驱、多个后继，于是"下一个是谁"不再唯一——遍历由此变成一件需要设计的事。二叉树是树的特例，也是所有树算法落到代码里的标准形态。

---

## 一、树的定义与术语

**树**：n（n ≥ 0）个结点的有限集合 T。n = 0 是空树；n > 0 时有一个特定的**根结点**，其余结点分成 m（m ≥ 0）个互不相交的集合 $T_0\ldots T_{m-1}$，每个集合本身又是一棵树，称为根的**子树**。

要点：除根外每个结点**有且只有一个直接前驱**（父结点），后继可以有 0 个或多个。这条"一父多子"是树与图的根本区别（图允许回路和多父）。

| 术语 | 定义 |
|---|---|
| 结点的度 | 该结点的子树个数 |
| 叶子 | 度为 0 的结点 |
| 子女 / 双亲 | 子树的根是子女，自己是子女的双亲 |
| 兄弟 | 同一双亲的子女互称 |
| 祖先 / 子孙 | 根到该结点路径上的所有结点（不含自己）/ 该结点之下的所有结点（不含自己） |
| 层次 | 根为第 1 层，其余 = 父层次 + 1 |
| 深度 / 高度 | 层次最大的结点的层次 |
| 树的度 | 所有结点度的最大值 |
| 有序树 | 子树有次序，交换位置就是另一棵树 |
| 森林 | m（m ≥ 0）棵互不相交的树的集合 |

## 二、树的四种存储表示

树是多叉的，指针域要么浪费要么不够，这是它比二叉树麻烦的地方。

| 表示 | 做法 | 代价 |
|---|---|---|
| 多指针 | 每个结点开 d 个子女指针（d 为树的度） | n 个结点共 n·d 个指针，只有 n-1 个有用，其余为空 |
| 父指针 | 每个结点存 (data, parent 下标) | 找父 O(1)，找子要扫全表 |
| 子女链表 | 每个结点挂一条子女链 | 找子方便，结点大小不一 |
| 左子女-右兄弟 | 每个结点两个指针：第一个子女、下一个兄弟 | 定长两指针，能表示任意多叉树 |

**左子女-右兄弟**是标准答案，因为任何树都能用它无损地变成一棵二叉树：

- 每个结点只保留指向**第一个子女**的指针；
- 其余子女通过**兄弟链**串起来：结点 p 的下一个兄弟，就是 p 的父结点的下一个子女。

```
data | firstChild | nextSibling
```

于是"找 p 的所有子女"变成"从 p->firstChild 出发，沿 nextSibling 走到头"。这个变换在第八节会正式写成"树转二叉树"。

## 三、树的遍历

**遍历**：按某种次序访问每个结点一次且仅一次。以这棵树为例：A 有子女 B、C、D，B 有子女 E、F，D 有子女 G。

```
        A
      / | \
     B  C  D
    / \    |
   E   F   G
```

树有三种遍历：

| 方式 | 次序 | 上面那棵树的输出 |
|---|---|---|
| 前序（先根） | 根 → 各子树依次前序 | A B E F C D G |
| 后序（后根） | 各子树依次后序 → 根 | E F B C G D A |
| 层次 | 逐层从左到右 | A B C D E F G |

递归写法极短，以后序为例：

```cpp
void postOrder(Node *p) {
    if (!p) return;
    for (Node *q = p->firstChild; q; q = q->nextSibling)
        postOrder(q);
    visit(p);
}
```

非递归要自己用栈。前序的非递归思路是"沿长子链一路向下，走到头就退栈转向兄弟"；后序则要在退栈时输出，因此栈里存的必须是"已经处理完子女"的结点。

**层次遍历用队列**：根入队，然后循环"出队一个、访问它、把它的所有子女入队"。第 5 讲的队列在这里第一次派上大用场。

## 四、二叉树

**二叉树**：n 个结点的有限集合，或为空，或由根及两棵互不相交的**左子树**、**右子树**组成。注意二叉树的子树有左右之分，**度为 1 的结点也要区分是左还是右**，所以二叉树不是"度不超过 2 的树"。

五种基本形态：空、只有根、根+左、根+右、根+左右。

### 4.1 五条性质

| 编号 | 内容 | 证明要点 |
|---|---|---|
| 1 | 第 i 层最多 $2^{i-1}$ 个结点 | 归纳：每层最多是上层的两倍 |
| 2 | 高 h 的二叉树最多 $2^h - 1$ 个结点，最少 h 个 | 等比数列求和 $1+2+\ldots +2^{h-1}$；每层至少 1 个 |
| 3 | 叶子数 $n_0$ = 度为 2 的结点数 $n_2 + 1$ | 见下 |
| 4 | n 个结点的完全二叉树高为 $\lceil \log_2(n+1)\rceil$ | 由 $2^{h-1}-1 < n \le 2^h-1$ 推 |
| 5 | 完全二叉树按层编号后，i 的父为 ⌊(i-1)/2⌋，左子女 2i+1，右子女 2i+2 | 编号即数组下标 |

性质 3 的证明值得背下来：设度为 1 的结点有 $n_1$ 个，总结点数 $n = n_0+n_1+n_2$；总边数（每个结点往上连一条）= $n-1 = n_1+2n_2$。两式相减得 **$n_0 = n_2+1$**。

性质 5 用 0 起编号（课件用 0 起）。若题目用 1 起编号，则父为 ⌊i/2⌋，左子女 2i，右子女 2i+1。

### 4.2 满二叉树与完全二叉树

- **满二叉树**：每一层的结点数都达到最大，高 h 时有 $2^h-1$ 个结点。
- **完全二叉树**：除最后一层外每层都满，最后一层从左到右连续排列，只在右边缺若干结点。

完全二叉树是"能用数组存"的那一类：编号连续，父子关系全靠下标算，不需要指针。这也是堆（第 8 讲）选完全二叉树的原因。

## 五、二叉树的存储

| 方式 | 结构 | 适用 |
|---|---|---|
| 数组 | 按层序编号，空位留空 | 完全二叉树；一般二叉树会大量浪费 |
| 二叉链表 | `data, leftChild, rightChild` | 通用，最常用 |
| 三叉链表 | 再加 `parent` | 需要频繁找父结点 |

数组存储的浪费有多严重：一棵只有 5 个结点、但全是右子女的单支二叉树，高度 5，编号会一直排到 $2^5-1 = 31$，必须开 31 个位置的数组，其中 26 个空着，而且不能压缩。所以一般二叉树一律用二叉链表。

> 旁注｜父指针表示法在别处还有用处：并查集（union-find）就是用"每个结点只存父结点"的数组实现的，查找根、路径压缩都靠它。这里不展开，知道"表示法要跟着操作走"即可。

## 六、由遍历序列确定二叉树

**前序 + 中序可以唯一确定一棵二叉树**：前序的第一个元素必是根；在中序里找到这个根，左边是左子树的中序、右边是右子树的中序；左子树的长度又决定了前序里哪一段属于左子树。然后递归。

```
前序：A B H F D E C K G
中序：H B D F A E K C G
        └─左─┘   └─右─┘
根 A；左子树前序 B H F D，中序 H B D F；右子树前序 E C K G，中序 E K C G
```

后序 + 中序同样可以（后序的最后一个元素是根），但**前序 + 后序不行**：无法区分"只有左子树"和"只有右子树"。

## 七、遍历能干什么

同一套递归骨架，把 `visit(p)` 换成别的语句，就得到不同的统计量：

| 需求 | 写法 |
|---|---|
| 结点数 | `1 + Size(left) + Size(right)` |
| 高度 | `1 + max(Height(left), Height(right))` |
| 叶子数 | 空返回 0，左右都空返回 1，否则两边相加 |
| 复制 | 新建根 → 递归复制左右子树 → 返回 |
| 判相等 | 都空为真；根值相等且左右都相等为真 |
| 建树 | 前序输入，遇空标记（如 `@`）返回 NULL |

**判断完全二叉树**有个巧办法：层序遍历，连空子女也入队；遇到第一个空结点后，若队列里还有非空结点，就不是完全二叉树。

## 八、树、森林与二叉树的转换

树 → 二叉树（左子女右兄弟）：

1. 每个结点的第一个子女，作为它的左子女；
2. 每个结点的下一个兄弟，作为它的右子女；
3. 根结点没有兄弟，所以转换后二叉树的根没有右子树。

森林 → 二叉树：先把每棵树转成二叉树，再把第二棵树的根作为第一棵树根的右子树，第三棵作为第二棵的右子树……依次串起来。

转换有三条必须记住的对应关系：

- 树的**前序** = 对应二叉树的**前序**
- 树的**后序** = 对应二叉树的**中序**
- 森林的**先根**/**后根** = 对应二叉树的**前序**/**中序**

这条对应关系让"树的遍历"不必单独写代码——转成二叉树，用二叉树的遍历即可。

## 十、易错点

1. 二叉树 ≠ 度不超过 2 的树。度为 1 时左右之分是结构的一部分，左右交换是另一棵树。
2. 性质 3 的 $n_0 = n_2+1$ 只对二叉树成立；推广到 m 叉树应是 $n_0 = 1 + \sum (i-1)\cdot n_i$。
3. 完全二叉树的编号公式有两套（0 起、1 起），考试先看清题目。
4. 前序 + 后序不能唯一确定二叉树，能确定的只有"前序+中序"或"后序+中序"。
5. 数组存储只适合完全二叉树。单支树的高度 h 会让数组开到 $2^h-1$。
6. 树的后序遍历对应二叉树的中序遍历，不是后序遍历——这一条最容易记反。

## 十二、一句话带走

树把"一对多"写成递归定义，二叉树把这个递归定义压成两个指针；于是遍历、统计、建树全都变成同一套递归骨架的变体。

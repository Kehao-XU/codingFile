## 0. 速查（考前一天过两遍）

1. 顺序表 AMN：插入 $n/2$，删除 $(n-1)/2$。插入位置有 $n+1$ 个，删除只有 $n$ 个。
2. 三对角矩阵：$k=2i+j$，共 $3n-2$ 个非零元（0 基）。
3. 对称矩阵只存下三角：$i\ge j$ 时 $k=i(i+1)/2+j$；$i<j$ 时交换 $i,j$。
4. 循环队列：空 `front==rear`，满 `(rear+1)%m==front`，元素个数 `(rear-front+m)%m`，最多存 $m-1$ 个。
5. 两栈共享：满 `top1+1==top2`。
6. 卡特兰数 $b_n=\dfrac{1}{n+1}\dbinom{2n}{n}$，同时是「出栈序列数」和「二叉树形态数」。
7. `next[j]` 是 $p[0..j-1]$ 的最长相等真前后缀长度，规定 `next[0]=-1`。
8. BF 最坏 $O(nm)$，KMP $O(n+m)$；KMP 的 `i` 不回退，靠滑动模式省时间。
9. isp/icp：`(` 1/6，`)` 6/1，`* /` 5/4，`+ -` 3/2。新运算符进栈前，弹出所有 `isp >= icp`。
10. Hanoi 移动 $2^n-1$ 次，递归调用 $2^{n+1}-1$ 次。
11. 广义表：`tail` 一定返回表；深度按展开后的括号层数算，空表算 1。
12. 二叉树：$n_0=n_2+1$；$n$ 个结点的二叉链表有 $n+1$ 个空指针域。
13. 完全二叉树：高度 $\lfloor\log_2 n\rfloor+1$；1 基编号下左子女 $2i$、右子女 $2i+1$、父 $\lfloor i/2\rfloor$。
14. 前序+中序、后序+中序能唯一还原；前序+后序不能。
15. 树转二叉树：左孩子右兄弟。树的**后根**遍历 = 二叉树的**中序**，前根 = 前序。
16. 线索树找中序前驱：`ltag==1` 取左指针；`ltag==0` 取左子树最右下的结点。
17. 堆：建堆 $O(n)$（从 $\lfloor(n-2)/2\rfloor$ 往前下沉），插入删除 $O(\log n)$，排序 $O(n\log n)$。
18. 霍夫曼：$n$ 个叶子共 $2n-1$ 个结点；WPL = 所有内部结点权值之和。
19. 递归改非递归：尾递归直接换循环；其余自己用栈存「返回地址 + 局部变量」。
20. `next[0]=-1` 是约定，1 基教材写作 `next[1]=0`，答题前先写一句用的是哪种。

## 1. 填空（15 题，15 分钟）

9. 高度为 5 的二叉树最多有 ______ 个结点。
10. 100 个结点的完全二叉树，高度是 ______。
11. 20 个结点的二叉链表，空指针域有 ______ 个。
12. 广义表 `(a, (b,c), ((d)))` 的长度是 ______，深度是 ______。
13. 4 个元素依次进栈，可能的出栈序列有 ______ 种。
14. 8 个叶子的霍夫曼树共有 ______ 个结点。
15. 序列 `9 17 23 45 53 65 78 87` ______（是 / 不是）小根堆。

<details><summary>答案</summary>

1. 50（$n/2$）
2. 12（$2\times4+4$）
3. 24（$6\times7/2+3$）
4. 5（$(8-3+10)\bmod 10$）

6. `-1 0 0 1 2 3`
7. `-1 0 -1 0 -1 3`
8. 19（$n_0=n_2+1$）
9. 31（$2^5-1$）
10. 7（$2^6-1=63<100\le127$）
11. 21（$n+1$）
12. 长度 3，深度 3
13. 14（$b_4$）
14. 15（$2n-1$）
15. 是

## 2. 手算（8 题，25 分钟）

1. 模式 `abaabcac`，写出 `next` 和 `nextval`。
2. 前序 `ABHFDECKG`、中序 `HBDFAEKCG`，还原二叉树并写出后序。
3. 中缀 `A+B*(C-D)-E/F`，写出后缀表达式，并说明 `-` 和 `*` 分别在哪一步出栈。
4. 权值 `{5,7,8,11}` 建霍夫曼树，求 WPL 和一组编码。
5. 最大堆 `20 15 12 10 8`，插入 18，写出调整过程和比较次数。
6. 完全二叉树 1000 个结点，求叶子数。
7. 一棵树的后根遍历是 `E B C D A`，它对应的二叉树的中序是什么？前序呢？
8. `{[()]}` 的括号匹配过程中，栈的最大深度是多少？栈里依次放过哪些字符？

<details><summary>答案</summary>

1. `next = -1 0 0 1 1 2 0 1`，`nextval = -1 0 -1 1 0 2 -1 1`
2. 后序 `HDFBKGCEA`（根 A；左子树 H、B、F(D)；右子树 E(空, C(K,G))）
3. 后缀 `ABCD-*+EF/-`。`-` 在遇到 `)` 时出栈，`*` 和 `+` 在遇到第二个 `-` 时依次出栈。
4. 合并 5+7=12，8+11=19，12+19=31，WPL $=12+19+31=62$。四个叶子都在第 2 层，编码可取 `5:00 7:01 8:10 11:11`，码长全是 2。
5. 先放末尾：`20 15 12 10 8 18`；18 与父 12 交换 → `20 15 18 10 8 12`；再与父 20 比，不再交换。共比较 2 次。
6. 叶子 500（第 10 层 489 个，第 9 层再补 11 个）。
7. 后根对应中序，所以中序就是 `E B C D A`；前序要看对应的二叉树（A 的孩子是 B、C、D，B 的孩子是 E），结果为 `A B E C D`。
8. 最大深度 3；依次放入 `{`、`[`、`(`，然后逐个弹出。

</details>

## 3. 算法默写（8 题，50 分钟，先写思路再写代码）

**3.1** 单链表原地反转，空间 $O(1)$。

<details><summary>思路与代码</summary>

遍历时先存后继，再掉头，最后把表头接到新首结点。

```c
Node *prev = NULL, *cur = head->link;
while (cur) {
    Node *nx = cur->link;   // 1. 记住后继
    cur->link = prev;       // 2. 掉头
    prev = cur;             // 3. 前进
    cur = nx;
}
head->link = prev;
```

</details>

**3.2** 判断单链表是否有环，空间 $O(1)$。

<details><summary>思路与代码</summary>

快慢指针，快指针每次两步，相遇则有环。

```c
Node *slow = head->link, *fast = head->link;
while (fast && fast->link) {
    slow = slow->link;
    fast = fast->link->link;
    if (slow == fast) return true;
}
return false;
```

</details>

**3.3** 统计二叉树的叶子结点数。

<details><summary>思路与代码</summary>

空树返回 0；没有孩子的结点返回 1；否则左右相加。

```c
int leaves(Node *p) {
    if (!p) return 0;
    if (!p->left && !p->right) return 1;
    return leaves(p->left) + leaves(p->right);
}
```

</details>

**3.4** 判断一棵二叉树是否为完全二叉树。

<details><summary>思路与代码</summary>

层序遍历，空孩子也入队。遇到第一个空结点后，再出现非空结点就不是完全二叉树。

```c
bool isComplete(Node *root) {
    if (!root) return true;
    queue<Node *> q; q.push(root);
    bool seenNull = false;
    while (!q.empty()) {
        Node *p = q.front(); q.pop();
        if (!p) { seenNull = true; continue; }
        if (seenNull) return false;
        q.push(p->left); q.push(p->right);
    }
    return true;
}
```

</details>

**3.5** 完全二叉树用数组存储（1 基），求结点 $i$ 和 $j$ 的最近公共祖先。

<details><summary>思路与代码</summary>

编号直接给出父子关系：$i$ 的父是 $\lfloor i/2\rfloor$。让大的那个先除以 2，相等时即为祖先。

```c
int lca(int i, int j) {
    while (i != j) {
        if (i > j) i /= 2; else j /= 2;
    }
    return i;
}
```

$O(\log n)$，不用建树。2011 和 2025 都考过。

</details>

**3.6** 循环队列的入队、出队、判满、计数。

<details><summary>思路与代码</summary>

牺牲一个单元：`front` 指向队头，`rear` 指向队尾的下一个位置。

```c
bool empty() const { return front == rear; }
bool full()  const { return (rear + 1) % m == front; }
int  count() const { return (rear - front + m) % m; }

bool enQueue(int x) {
    if (full()) return false;
    rear = (rear + 1) % m; a[rear] = x;   // 先移再放
    return true;
}
bool deQueue(int &x) {
    if (empty()) return false;
    front = (front + 1) % m; x = a[front];
    return true;
}
```

</details>

**3.7** 非递归求二叉树的高度。

<details><summary>思路与代码</summary>

按层遍历，每处理完一层高度加一。

```c
int height(Node *root) {
    if (!root) return 0;
    queue<Node *> q; q.push(root);
    int h = 0;
    while (!q.empty()) {
        int n = q.size();               // 当前层的结点数
        for (int i = 0; i < n; i++) {
            Node *p = q.front(); q.pop();
            if (p->left)  q.push(p->left);
            if (p->right) q.push(p->right);
        }
        ++h;
    }
    return h;
}
```

</details>

**3.8** 合并两个有序单链表，复用原结点。

<details><summary>思路与代码</summary>

尾指针在结果链上走；某个表走完后，把另一个表的剩余整段挂上。

```c
Node *merge(Node *a, Node *b) {
    Node *head = new Node(0), *tail = head;
    Node *pa = a->link, *pb = b->link;
    while (pa && pb) {
        if (pa->data <= pb->data) { tail->link = pa; pa = pa->link; }
        else                      { tail->link = pb; pb = pb->link; }
        tail = tail->link;
    }
    tail->link = pa ? pa : pb;
    return head;
}
```

</details>

## 4. 简答（5 题，各两三句话）

**4.1** 为什么 KMP 的 `i` 不用回退？

**4.2** 建堆为什么是 $O(n)$ 而不是 $O(n\log n)$？

**4.3** 递归为什么可能栈溢出？哪类递归可以直接改成循环？

**4.4** 树的后根遍历为什么等于对应二叉树的中序？

**4.5** 循环队列为什么要牺牲一个存储单元？

<details><summary>答案</summary>

**4.1** 失配时 `next[j]=k` 说明 $p[0..k-1]$ 既是已匹配文本的真前缀也是真后缀，模式右移 $j-k$ 位后前缀已经对上了，所以 `i` 停住即可继续比。

**4.2** 自底向上时，高度为 $h$ 的结点最多约 $n/2^{h+1}$ 个，每个最多下沉 $h$ 层，求和 $\sum h\cdot n/2^{h+1}=O(n)$。多数结点在底层，几乎不用下沉。

**4.3** 每层调用都要在系统栈压一个活动记录（返回地址 + 局部变量），深度大时栈空间不够。尾递归（递归调用是最后一步、返回后不再计算）可以直接改成循环。

**4.4** 左孩子-右兄弟表示把「孩子」变成了左子树、「兄弟」变成了右子树，后根是「先子后根」，对应二叉树的「先左后根」，即中序。

**4.5** 若不牺牲，队空 `front==rear` 和队满 `rear==front` 无法区分；牺牲一个单元后，队满变成 `(rear+1)%m==front`，不用额外计数器。

</details>

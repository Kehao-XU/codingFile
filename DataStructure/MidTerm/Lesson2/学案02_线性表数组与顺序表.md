## 一、线性表

**线性表**：n（n ≥ 0）个数据元素的有限序列，记作 $L = (k_0, k_1, \ldots, k_{n-1})$。$k_0$ 叫表头，$k_{n-1}$ 叫表尾，n 叫表长；n = 0 时是空表。除表头外每个元素有且只有一个**直接前驱**，除表尾外每个元素有且只有一个**直接后继**。

课件列的五个基本操作，后面实现的是后三个：

| 操作 | 语义 |
|---|---|
| 访问 Get(i) | 取第 i 个元素，0 ≤ i < n |
| 更新 Set(i, x) | 把第 i 个元素改为 x |
| 查找 Find(x) | 返回第一个值为 x 的元素下标，找不到返回 -1 |
| 插入 Insert(x, i) | 把 x 放到第 i 个位置，原第 i, i+1, …, n-1 个元素依次后移一位，0 ≤ i ≤ n |
| 删除 Remove(i) | 删掉第 i 个元素，原第 i+1, …, n-1 个元素依次前移一位，0 ≤ i < n |

> 旁注｜**广义表**放松了"同类型"这一条，允许元素本身又是一张表，所以概念上线性表的元素类型可以不同。本讲所有实现都要求同类型，否则没法用连续空间。广义表在第 6 讲。

## 二、数组：随机访问是算出来的

数组把元素放在一片连续存储单元里，每个元素占 s 个字节。记 LOC(i) 为第 i 个元素的首字节地址，则

```
LOC(i) = LOC(0) + i * s
```

一次乘法加一次加法，与 n 无关，这就是"随机访问 O(1)"的全部秘密。多维也同理，只是把下标折算成一个线性序号。

设二维数组 A 有 $t_1$ 行、$t_2$ 列，每行 $t_2$ 个元素：

| 存放方式 | 地址公式 |
|---|---|
| 行优先 | $LOC(i, j) = LOC(0, 0) + (i\cdot t_2 + j)\cdot s$ |
| 列优先 | $LOC(i, j) = LOC(0, 0) + (j\cdot t_1 + i)\cdot s$ |

三维数组 $A[t_1][t_2][t_3]$，按"页 / 行 / 列"顺序存放：

$$
LOC(i, j, k) = LOC(0,0,0) + (i \cdot t_2 \cdot t_3 + j \cdot t_3 + k) \cdot s
$$

$i \cdot t_2 \cdot t_3$ 是前 i 页的元素总数，$j \cdot t_3$ 是第 i 页前 j 行的元素总数，$k$ 是本行前 k 列。n 维就是这个式子的推广，每一项是"该维之前已跨过的元素数"。

下标不一定从 0 开始。若 $A[c_1..d_1, c_2..d_2]$，先把下标平移：$i' = i - c_1$，$j' = j - c_2$，再套上面的公式。

**练习题（课件原题）**：A 的元素由 6 个字符组成，行下标 i = 0..8，列下标 j = 1..10。行优先存储时 A[8, 5] 的地址，与列优先存储时哪个元素的地址相同？

行优先：以 A[0,1] 为基准，偏移 = (8-0)×10 + (5-1) = 84。
列优先：设目标为 A[i, j]，偏移 = (j-1)×9 + (i-0)。令其等于 84，得 j = 10、i = 3，即 A[3, 10]。

> 旁注｜动态数组扩容不是 O(1)。`std::vector` 每次按倍数扩容，把 n 次插入的总代价摊开算，平均每次仍是 O(1)，这叫**摊还分析**。课件只提到"动态分配时间开销较大"，没展开，考试不考。

## 三、特殊矩阵：把不该存的东西省掉

矩阵压缩的前提是非零元素的分布有规律，或者非零元素极少。

**对称矩阵**：n×n 且 $a_{ij} = a_{ji}$，独立元素只有 n(n+1)/2 个。只存下三角（含对角线），按行塞进一维数组 B：

$i \ge j$ 时：$k = i(i+1)/2 + j$，$B[k]$ 存 $a_{ij}$。

$i < j$ 时：$a_{ij}$ 不在 $B$ 中，取 $a_{ji}$，即 $k = j(j+1)/2 + i$。

式子的来源：前 i 行共 1+2+…+i = i(i+1)/2 个元素，本行前面还有 j 个。

**三对角矩阵**：只有主对角线和上下各一条对角线非零，共 3n-2 个非零元素。按行存入 B，元素 $a_{ij}$ 的位置是

```
k = 2i + j        （要求 i-1 ≤ j ≤ i+1，否则该元素为 0）
```

反过来，已知 k 求 (i, j)：解不等式 3i-1 ≤ k < 3(i+1)-1，得

```
i = ⌊(k+1)/3⌋,   j = k - 2i
```

**稀疏矩阵**：m×n 的矩阵只有 t 个非零元素，且 t 远小于 m·n。每个非零元素存成三元组 (row, col, value)，所有三元组按行优先、同行为列递增排列。

转置的朴素做法：对每一列 c（共 Cols 列），扫描整个三元组表找出列号为 c 的项，行号列号互换后依次存入结果。外层 Cols 趟、内层 Terms 次，O(Cols × Terms)；当 Terms 与 Rows×Cols 同阶时退化为 $O(Rows \times Cols^2)$。

快速转置用两个辅助数组把"该放哪"一次算出来：

- `rowSize[c]`：原矩阵第 c 列的非零元素个数，也就是转置后第 c 行的元素个数
- `rowStart[c]`：转置后第 c 行的第一个元素在结果表中的下标，`rowStart[0] = 0`，`rowStart[c] = rowStart[c-1] + rowSize[c-1]`

然后顺序扫描原三元组表，对每个项查 `rowStart[col]` 得到落点，放好后 `rowStart[col]++` 指向本行下一个空位。四个循环分别 O(Cols)、O(Terms)、O(Cols)、O(Terms)，总计 **O(max(Cols, Terms))**。

## 四、顺序表

**顺序表**：用一片连续空间依次存放线性表元素，逻辑相邻即物理相邻，因此可以随机访问；代价是所有元素必须同类型，且容量要预先确定。

用数组 `list` 存元素，`last` 记录**最后一个元素的下标**（空表时 last = -1），表长为 last+1，容量为 maxSize。

**查找**：从 0 扫到 last，逐个比较。若每个元素被查概率相同且查找必成功，平均比较次数

```
ACN = (1/n) × Σ(i = 0 … n-1) (i+1) = (n+1)/2
```

查找失败时要比较 n 次。

**插入**：在第 i 个位置插入，需要把 a[i..n-1] 共 n-i 个元素后移一位，空出位置。若 n+1 个可插入位置等概率，平均移动次数

```
AMN = (1/(n+1)) × Σ(i = 0 … n) (n-i) = n/2
```

**删除**：删第 i 个元素，需要把 a[i+1..n-1] 共 n-1-i 个元素前移一位。若 n 个位置等概率，平均移动次数

```
AMN = (1/n) × Σ(i = 0 … n-1) (n-1-i) = (n-1)/2
```

| 操作 | 最好 | 最坏 | 平均 |
|---|---|---|---|
| 查找（成功） | 1 次，O(1) | n 次，O(n) | (n+1)/2，O(n) |
| 插入 | 0 次（表尾），O(1) | n 次（表头），O(n) | n/2，O(n) |
| 删除 | 0 次（表尾），O(1) | n-1 次（表头），O(n) | (n-1)/2，O(n) |

n = 127 时，插入平均移动 63.5 个元素，删除平均移动 63 个——这两个数字是课件练习，也正是下面任务 1 要实测的东西。

## 五、多项式：为什么需要第四种存储

n 阶多项式 $P(x) = a_0 + a_1x + \ldots + a_nx^n$ 有 n+1 项。三种存法：

| 存法 | 做法 | 问题 |
|---|---|---|
| 定长系数数组 | `float coef[maxDegree+1]` | 阶数远小于 maxDegree 时大片空转 |
| 动态系数数组 | 按实际阶数 new 一个 | 指数不连续时仍浪费（如 $3 + 5x^{50} - 14x^{101}$ 要 102 个槽） |
| 系数 + 指数表 | 每项存 (coef, exp)，按指数升序 | 省空间，代价是查找变慢 |

第三种是重点。`Poly_Add` 用两个指针分别扫描 A、B 的项表：指数相等则系数相加（和为 0 就丢弃），不等则把指数小的那项抄进结果。三个循环合起来 O(m+n)，其中 m、n 是两多项式的项数。

## 七、易错点

1. 插入位置 i 的合法范围是 0..n（可以插在表尾），删除是 0..n-1。差这一个边界，插入校验收紧后就再也插不进最后一个位置。
2. 移动方向：插入必须从表尾往前搬，否则前面的元素被覆盖；删除必须从前往后搬。
3. 三对角 `k = 2i+j` 是从 0 计数的版本。考题若给 A[1..100, 1..100]，先减 1 再用公式。
4. 对称矩阵只存了一半，i < j 时必须换成 (j, i) 再套公式。
5. 快速转置是 O(max(Cols, Terms))，不是 O(Cols×Terms)；写后者说明没理解"每个非零元只搬一次"。
6. 顺序表长度是 last+1。`last` 是"末元素下标"，不是长度。

## 九、一句话带走

数组的 O(1) 来自地址公式，顺序表的 O(n) 来自元素搬移；压缩存储的本质是换一份"下标的算法"。

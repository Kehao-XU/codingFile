## 2. 复杂度

### 一句话

大 $O$ 描述的是**增长阶**，不是运行时间；它忽略常数和低阶项，只保留主导项。

### 要记的

- 定义：存在常数 $c>0$ 和 $n_0$，当 $n>n_0$ 时 $T(n)\le c\cdot f(n)$，记 $T(n)=O(f(n))$。它给的是**上界**，不是精确值，也不是下界。
- 常见阶从小到大：$O(1) < O(\log n) < O(n) < O(n\log n) < O(n^2) < O(n^3) < O(2^n) < O(n!)$。
- **程序步**：基本操作执行的次数，用来把「一段代码」变成「一个关于 $n$ 的函数」。
- 循环的算法：一层循环看循环次数，嵌套就相乘，但要看**内层是否依赖外层**。
- 递归的算法：写出递推式再解，如 $T(n)=2T(n/2)+O(n)\Rightarrow O(n\log n)$。

### 典型手法

```c
for (i = 1; i <= n; i++)
    for (j = i; j <= n; j++)   // 注意 j 从 i 开始
        s += a[i][j];
```

执行次数是 $\sum_{i=1}^{n}(n-i+1)=\dfrac{n(n+1)}{2}=O(n^2)$。内层循环的次数虽然随 $i$ 变化，但求和之后仍然是平方级——**不要把「内层依赖外层」直接当成 $\log$**，只有外层每次把规模折半才是 $\log$。

```c
for (i = 1; i <= n; i *= 2)
    for (j = 1; j <= n; j++)
        s++;
```

外层 $\lfloor\log_2 n\rfloor+1$ 次，内层 $n$ 次，乘起来 $O(n\log n)$。

### 易错

- 只看最内层语句执行了多少次，而不是看循环嵌套了几层。
- $O(2n)$、$O(n/2)$ 都写成 $O(n)$。
- 递归里的重复计算要单独算：朴素 Fib 的 $T(n)=O(2^n)$，不是因为循环，而是因为调用树是指数级的。

## 3. 线性表

### 一句话

顺序表靠**下标**定位，代价是插入删除要搬元素；链表靠**指针**定位，代价是访问第 $i$ 个结点要走 $i$ 步。

### 顺序表：平均移动次数（AMN）

设表长 $n$，各位置等概率。

| 操作 | 合法位置数 | 平均移动 |
|---|---|---|
| 插入 | $n+1$ | $\dfrac{n}{2}$ |
| 删除 | $n$ | $\dfrac{n-1}{2}$ |

推导（插入）：在第 $i$ 个位置插入要移动 $n-i$ 个元素，$i=0..n$ 等概率，

$$\text{AMN}=\frac{1}{n+1}\sum_{i=0}^{n}(n-i)=\frac{1}{n+1}\cdot\frac{n(n+1)}{2}=\frac{n}{2}.$$

这两个公式要能从零推出来，考试常要求写推导过程。

### 地址计算

- 一维数组：$\text{loc}(a_i)=\text{loc}(a_0)+i\times L$。
- 二维按行优先：$\text{loc}(a_{ij})=\text{loc}(a_{00})+(i\times n+j)\times L$。
- 三对角矩阵压缩（$n\times n$，只存 $|i-j|\le 1$ 的 $3n-2$ 个元素）：$k=2i+j$，反解 $i=\left\lfloor\dfrac{k+1}{3}\right\rfloor,\ j=k-2i$。
- 对称矩阵：只存下三角，$i\ge j$ 时 $k=\dfrac{i(i+1)}{2}+j$；$i<j$ 时交换 $i,j$。

### 链表

- 单链表：判空 `head->link == NULL`；在第 $i$ 个位置插入，要先找到第 $i-1$ 个结点，$O(n)$。
- 带头结点 vs 不带头结点：带头结点可以让「在第一个位置插入/删除」和其他位置的操作统一，不用特判。
- 循环单链表：判空 `head->link == head`；从任意结点出发都能遍历全表。
- 双向链表：插入和删除都要改**四条**指针，顺序不能错（先接新的，后断旧的）。

双向链表在 `p` 前插入 `s`：

```c
s->prior = p->prior;  p->prior->next = s;
s->next  = p;         p->prior = s;
```

- 静态链表：用数组模拟，`next` 存的是**下标**而不是地址；0 号单元常作头结点。

### 典型题

**题 3.1** 长度为 $n$ 的顺序表，在第 $i$ 个位置插入一个元素，平均要移动多少个元素？若 $n=1000$，平均移动多少次？

<details><summary>答案</summary>

$n/2$；$n=1000$ 时为 500 次。注意「插入位置」有 $0,1,\dots,n$ 共 $n+1$ 个可选，分母是 $n+1$ 不是 $n$，这是本题最容易错的地方。

</details>

**题 3.2** 写一个算法，在 $O(1)$ 空间内把单链表反转。

<details><summary>答案</summary>

三指针法，`prev` 初始为 `NULL`，逐个把 `cur->link` 指向 `prev`：

```c
Node *prev = NULL, *cur = head->link;
while (cur) {
    Node *next = cur->link;   // 先记住后继
    cur->link = prev;         // 掉头
    prev = cur;  cur = next;
}
head->link = prev;
```

时间 $O(n)$，空间 $O(1)$。**必须先保存 next**，否则掉头后链表断开。

</details>

**题 3.3** 判断单链表是否有环，要求 $O(1)$ 空间。

<details><summary>答案</summary>

快慢指针。`slow` 每次走一步，`fast` 每次走两步；若相遇则有环，`fast` 先到 `NULL` 则无环。

</details>

## 4. 串与模式匹配

### 一句话

BF 每次失配都从模式头重来；KMP 用 `next` 数组记住「已经匹配的部分里，最长的相等前后缀」，让模式右滑而不是从头比。

### BF

最坏 $O(nm)$：文本 $n$ 个字符、模式 $m$ 个字符，每个起点都比到最后一个字符才失配。

典型的最坏输入：文本 `aaaa…a`、模式 `aaaab`（$m=5$）。每个起点都要比到第 5 个字符才失配，所以单次要 $m$ 次；一共有 $n-m+1$ 个起点，合计 $(n-m+1)\times m$ 次。

### KMP

- `next[j]` 的定义：$p[0..j-1]$ 的**最长相等真前缀与真后缀**的长度，约定 `next[0] = -1`。
- 匹配时 `i` 只增不减；失配时 `j = next[j]`。
- 复杂度 $O(n+m)$。证明的关键是摊还：`j` 每次回退都会减少，而它只可能通过 `i` 前进而增加，总额不超过 $n$，所以总比较次数 $\le 2n$。

手算 `next`（0 基、`next[0]=-1`）：

```
p    = a b a a b c a c
下标 = 0 1 2 3 4 5 6 7
next = -1 0 0 1 1 2 0 1
```

验证 `next[5]=2`：$p[0..4]=$ `abaab`，真前缀 `ab` 与真后缀 `ab` 相等，长度 2。

**优化版 nextval**：若 $p[j]=p[\text{next}[j]]$，说明退过去也必然失配，直接再退一格。对 `aaaa`：普通 `next` 为 `-1 0 1 2`，`nextval` 为 `-1 -1 -1 -1`。

### 典型题

**题 4.1** 求模式 `ababaaab` 的 `next` 与 `nextval`。

<details><summary>答案</summary>

```
p       = a b a b a a a b
下标    = 0 1 2 3 4 5 6 7
next    = -1 0 0 1 2 3 1 1
nextval = -1 0 -1 0 -1 3 1 0
```

`nextval[j]` 的规则：若 $p[j]=p[\text{next}[j]]$ 则取 `nextval[next[j]]`，否则取 `next[j]`。

验算最后一位：`p[7]='b'`，`next[7]=1`，而 `p[1]='b'`，两者相同，所以要取 `nextval[1]=0`，不是 `next[7]` 本身。

</details>

**题 4.2** 为什么 KMP 的 `i` 不需要回退？

<details><summary>答案</summary>

设当前已经匹配了 `j` 个字符，即 `t[i-j..i-1] == p[0..j-1]`。失配时取 `k = next[j]`，含义是 `p[0..k-1]` 既是这段已匹配文本的真前缀、又是它的真后缀。于是把模式右移 `j-k` 位后，`p[0..k-1]` 与 `t[i-k..i-1]` 必然相同，`i` 停在原地就能继续比。BF 没有这个信息，只能把 `i` 退回窗口开头重来。

</details>

## 5. 栈与队列

### 一句话

栈是后进先出，队列是先进先出；两者都能顺序存储，也都能链式存储。考点集中在**边界条件**：栈满/栈空、队满/队空。

### 顺序栈

- `top` 指向**栈顶元素**，初值 $-1$；空：`top == -1`；满：`top == maxSize-1`。
- 进栈：先 `++top` 再放；出栈：先取再 `--top`。

### 两栈共享空间

数组 `data[0..maxSize-1]`，栈 1 从 0 往右长，栈 2 从 `maxSize-1` 往左长。

- 判满：`top1 + 1 == top2`。
- 优点：两个栈的空间可以互相借用，只有**总和**满了才溢出。

### 循环队列（牺牲一个单元）

- `front` 指向队头元素，`rear` 指向队尾元素的**下一个**位置。
- 空：`front == rear`；满：`(rear+1) % maxSize == front`。
- 元素个数：`(rear - front + maxSize) % maxSize`。
- 容量为 `maxSize` 的数组，实际最多存 `maxSize-1` 个元素——这就是「牺牲一个单元」。

### 表达式求值

- 中缀转后缀：遇到操作数直接输出；遇到运算符，把栈顶所有 `isp >= icp` 的弹出再入栈；右括号一路弹到左括号。
- `isp` 是运算符在**栈里**时用的优先级，`icp` 是它**刚读进来、还没进栈**时用的优先级：

| 运算符 | `(` | `)` | `*` `/` | `+` `-` |
|---|---|---|---|---|
| `isp` | 1 | 6 | 5 | 3 |
| `icp` | 6 | 1 | 4 | 2 |

括号的两个值是故意对调的：`(` 在栈外时最大（保证它压得住栈里的一切），在栈内时最小（保证后面的运算符都能压在它上面）。

`A+B*(C-D)-E/F` 的后缀是 `ABCD-*+EF/-`。

### 典型题

**题 5.1** 数组大小 8 的循环队列，最多能存几个元素？写出判满条件。

<details><summary>答案</summary>

7 个。判满 `(rear+1) % 8 == front`。若想存满 8 个，需要额外加一个计数器或标志位。

</details>

**题 5.2** 输入序列 1,2,3,4，能否得到出栈序列 3,1,2,4？说明理由。

<details><summary>答案</summary>

不能。要 3 先出栈，栈里必须是 `[1,2,3]`，3 出栈后栈顶是 2，下一个只能是 2 或 4，不可能是 1。

合法的出栈序列个数是卡特兰数 $C_n=\dfrac{1}{n+1}\dbinom{2n}{n}$，$n=4$ 时为 14 种。

</details>

**题 5.3** 用栈判断表达式中的括号是否匹配，写出思路。

<details><summary>答案</summary>

扫一遍：左括号入栈；右括号时弹出栈顶并检查类型是否对应，栈空则失败；扫完栈必须为空。三种失败情形：右括号多、类型不对、左括号多。

</details>

## 6. 递归与广义表

### 一句话

递归 = 出口 + 把问题化成规模更小的同类问题；广义表 = 元素可以又是表的表。

### Hanoi

- 移动次数 $2^n-1$。
- 递归调用次数 $2^{n+1}-1$（把 $n=0$ 的空调用也算上）。
- 三句话：把上面 $n-1$ 个移到中转柱，把最大的移到目标柱，再把那 $n-1$ 个移过去。

### 递归转非递归

两种手段：

1. **尾递归**（递归调用是函数的最后一步，例如带累加器参数的阶乘）可以直接改成循环，因为返回时不需要再做任何事。注意朴素的 `fact(n) = n * fact(n-1)` 和 Fib 的递归版本都**不是**尾递归，它们的返回值还要参与运算。
2. 一般递归要**自己用栈模拟系统栈**，保存「返回地址 + 局部变量」。

Fibonacci 的迭代版属于第二种思路的简化：它不需要栈，因为递推只依赖紧邻的前两项，保存 `a`、`b` 两个变量就够。

考试常问：为什么递归可能栈溢出？因为每层调用都要在系统栈上压一个活动记录，深度大时栈空间不够。

### 广义表

- 表头 `head(LS)`：第一个元素（可能是原子，也可能是子表）。
- 表尾 `tail(LS)`：去掉表头后剩下的部分，**一定是一个表**（可能是空表）。
- 深度：**展开后**括号的最大嵌套层数（原子的深度为 0，空表深度为 1）。
- 长度：最外层元素的个数。

例：$LS=(a,(b,c),((d)))$，长度 3，深度 3，`head(LS)=a`，`tail(LS)=((b,c),((d)))`。

### 典型题

**题 6.1** 求 $LS=((a,b),((c)),d)$ 的长度、深度，以及 `head(tail(LS))`。

<details><summary>答案</summary>

长度 3（元素是 `(a,b)`、`((c))`、`d`），深度 3。

`tail(LS) = (((c)),d)`，`head(tail(LS)) = ((c))`。

</details>

**题 6.2** 8 皇后有多少个解？用回溯法时，如何判断某个位置能否放皇后？

<details><summary>答案</summary>

92 个解。用三个标记数组：`col[j]`、主对角线 `md[n+r-j-1]`、次对角线 `sd[r+j]`；落子时置位，回溯时复位。

</details>

## 7. 树与二叉树

### 一句话

二叉树的定义是递归的，所以几乎所有操作都写成递归；考试的核心是**性质**、**遍历**、**由遍历序列还原树**。

### 必背性质

- 结点数 $n=n_0+n_1+n_2$，且 $n_0=n_2+1$（叶子比度为 2 的结点多一个）。
- 第 $i$ 层最多 $2^{i-1}$ 个结点（根为第 1 层）。
- 高度为 $h$ 的二叉树最多 $2^h-1$ 个结点。
- $n$ 个结点的完全二叉树高度 $h=\lfloor\log_2 n\rfloor+1$。
- 完全二叉树按层编号（从 1 开始）：结点 $i$ 的左子女是 $2i$，右子女 $2i+1$，父结点是 $\lfloor i/2\rfloor$。
- $n$ 个结点的二叉链表有 $n+1$ 个空指针域（每个结点 2 个指针，共 $2n$ 个，其中 $n-1$ 条边用了 $n-1$ 个）。

### 遍历

前序（根左右）、中序（左根右）、后序（左右根）、层序（队列）。

两个必须记牢的结论：

1. **前序 + 中序** 或 **后序 + 中序** 能唯一还原一棵二叉树；前序 + 后序 **不能**（分不清只有一个孩子时是左还是右）。
2. 中序序列 + 任一遍历，实质是「用根把中序切成左右两半」，递归下去。

### 建树模板

```c
Node *build(const char *pre, const char *in, int n) {
    if (n == 0) return NULL;
    char root = pre[0];
    int k = 0;
    while (in[k] != root) k++;          // 根在中序中的位置
    Node *p = new Node(root);
    p->left  = build(pre + 1,     in,     k);
    p->right = build(pre + k + 1, in + k + 1, n - k - 1);
    return p;
}
```

### 线索二叉树

- 利用 $n+1$ 个空指针域：空的左指针指向前驱，空的右指针指向后继。
- 为了区分「指针」和「线索」，每个结点加两个标志位 `ltag`、`rtag`。
- 中序线索化后，可以不用栈、不用递归地中序遍历。

找**中序前驱**分两种：`ltag == 1` 时左指针就是线索，直接指向前驱；`ltag == 0` 时左指针指向真正的左孩子，此时前驱是**左子树中最右下的那个结点**。找后继对称：`rtag == 1` 取右指针，否则取右子树最左下结点。

### 树、森林与二叉树的转换

这是四份卷子里出现频率最高的考点之一，但很容易记混：

- **树转二叉树**用「左孩子-右兄弟」：每个结点的第一个孩子变左子女，其余兄弟依次挂在右链上。
- **森林转二叉树**：各棵树先各自转换，再把第 2、3… 棵树的根作为前一棵树根的右子女串起来。
- 因此森林转成的二叉树，根结点的**右子树**装的是「除第一棵树以外的所有结点」——这是常被拿来出填空的结论。
- **遍历对应关系**：树的前根遍历 = 二叉树的**前序**；树的后根遍历 = 二叉树的**中序**。森林同理。

> 旁注｜为什么后根对应中序：后根是「先处理所有孩子，再处理根」，转成二叉树后「孩子」变成了左子树，于是顺序正好是「左—根」，也就是中序。

### 典型题

**题 7.1** 前序 `ABHFDECKG`，中序 `HBDFAEKCG`，还原二叉树并写出后序。

<details><summary>答案</summary>

根 `A`；中序里 `A` 左边 `HBDF` 是左子树、右边 `EKCG` 是右子树，递归下去得到后序：

`HDFBKGCEA`（与 `MidTerm/Lesson7/log/binarytree.txt` 的实测一致）。

</details>

**题 7.2** 一棵完全二叉树有 1000 个结点，求叶子数。

<details><summary>答案</summary>

$n=1000$，高度 $h=\lfloor\log_2 1000\rfloor+1=10$。

第 10 层有 $1000-(2^9-1)=489$ 个结点，都是叶子；第 9 层有 $2^8=256$ 个结点，其中 $\lceil 489/2\rceil=245$ 个有孩子，剩下 $256-245=11$ 个是叶子。

叶子总数 $489+11=500$。

</details>

**题 7.3** 写出判断完全二叉树的算法。

<details><summary>答案</summary>

层序遍历，空孩子也入队。第一次遇到空结点后置标志；之后再遇到非空结点就返回 false。

</details>

**题 7.4** 完全二叉树用数组存储（下标从 1 开始），求结点 $i$ 与 $j$ 的最近公共祖先。

<details><summary>答案</summary>

不用建树，直接用编号关系：深度不同时，把深的那个不断除以 2（`i /= 2`）直到同层；然后两者同时除以 2，第一次相等时就是 LCA。

```c
while (i != j) {
    if (i > j) i /= 2; else j /= 2;
}
return i;
```

$O(\log n)$，$O(1)$ 空间。2011 和 2025 两年都考了这道题，只是换了个问法。

</details>

**题 7.5** 一棵树的后根遍历序列，和它对应的二叉树（左孩子-右兄弟表示）的哪种遍历序列相同？为什么？

<details><summary>答案</summary>

中序。因为左孩子-右兄弟表示法把「孩子」变成了左子树、「兄弟」变成了右子树，后根是「先子后根」，对应二叉树的「先左后根」，即中序。前根遍历则对应前序。

</details>

## 8. 堆、霍夫曼与 Catalan

### 一句话

堆是「用数组存的完全二叉树」，霍夫曼是「每次合并最小的两个」，Catalan 数是「$n$ 个结点的二叉树有多少种不同形态」。

### 堆

- 小根堆：$a[i]\le a[2i+1]$ 且 $a[i]\le a[2i+2]$（0 基）；大根堆反过来。
- 插入：放到数组末尾，然后**上浮**，$O(\log n)$。
- 删除堆顶：把末尾元素放到堆顶，然后**下沉**，$O(\log n)$。
- 建堆：从最后一个非叶结点 $\lfloor(n-2)/2\rfloor$ 开始往前**下沉**，总代价 $O(n)$——不是 $O(n\log n)$。
- 堆排序：建大根堆 $O(n)$，然后 $n-1$ 次「堆顶与末尾交换 + 下沉」，共 $O(n\log n)$。

「建堆为什么是 $O(n)$」是常考简答：高度为 $h$ 的结点最多 $n/2^{h+1}$ 个，每个下沉 $O(h)$，求和 $\sum h\cdot n/2^{h+1}=O(n)$。

### 霍夫曼

- 每次从森林里取权值最小的两棵树，合并成新树，直到只剩一棵。
- WPL = 所有叶子权值 × 深度之和 = 所有**内部结点权值之和**（后者算起来更快）。
- $n$ 个叶子的霍夫曼树有 $2n-1$ 个结点，没有度为 1 的结点。
- 前缀编码：没有一个编码是另一个的前缀，所以解码无歧义。

### Catalan

$n$ 个结点的二叉树共有多少种**不同形态**（结点值不计，只看形状）：

$$b_n=\frac{1}{n+1}\binom{2n}{n},\qquad b_0..b_8=1,1,2,5,14,42,132,429,1430.$$

如果题目额外说「$n$ 个结点的值互不相同」，答案要再乘 $n!$，因为每一种形态有 $n!$ 种标号方式。Catalan 数只数形态。

同一个数还回答了：$n$ 个元素有多少种合法出栈序列、$n$ 对括号有多少种合法嵌套、凸 $n+2$ 边形有多少种三角剖分。

### 典型题

**题 8.1** 权值 $\{7,5,4,2\}$，构造霍夫曼树，求 WPL 和编码。

<details><summary>答案</summary>

合并 2+4=6，再 5+6=11，再 7+11=18。

WPL $=7\times1+5\times2+4\times3+2\times3=7+10+12+6=35$；也可以用内部结点之和 $6+11+18=35$ 验证。

一组编码（不唯一）：`A=0, T=10, C=110, S=111`。

</details>

**题 8.2** 判断序列 `{9,17,23,45,53,65,78,87}` 是否是最小堆。若不是，调整成最小堆。

<details><summary>答案</summary>

父结点与子女比较：$a[0]=9$ 的子女 17、23 都不小于 9；$a[1]=17$ 的子女 45、53 都大于 17……逐层检查全部满足，所以是最小堆。

这组数正好是第 8 讲堆排序那组 `{53,17,78,9,45,65,87,23}` 升序排完的结果。注意堆排序排升序时建的是**大根堆**，别把「升序的数组」误当成「小根堆的构造过程」。

</details>

**题 8.3** 为什么建堆是 $O(n)$ 而不是 $O(n\log n)$？

<details><summary>答案</summary>

自底向上建堆时，把「结点的高度」定义为它到最远叶子的边数。高度为 $h$ 的结点最多有 $\left\lceil\dfrac{n}{2^{h+1}}\right\rceil$ 个，每个最多下沉 $h$ 层，总代价 $\sum_{h\ge0} h\cdot\dfrac{n}{2^{h+1}}=O(n)$。直观点说：绝大多数结点都在最底下，它们根本不用下沉。

</details>

## 9. 易错点清单

考前扫一遍，每条都对应一次真实踩坑。

1. 顺序表插入的位置有 $n+1$ 个，删除只有 $n$ 个——AMN 分母不同。
2. 插入要从后往前搬，删除要从前往后搬。
3. 三对角矩阵是 $3n-2$ 个元素，不是 $3n$；$k=2i+j$ 不是 $3i+j$。
4. 链表反转必须先保存 `next`，再改 `link`。
5. 带头结点的链表，`head->link` 才是第一个元素，`head->data` 不用。
6. `next[0] = -1` 是**约定**，不同教材可能从 1 开始编号，答题时先说明约定。
7. `nextval` 只在模式自身重复度高时才有明显收益。
8. 循环队列牺牲一个单元，容量 $m$ 的数组最多存 $m-1$ 个。
9. 判空和判满都可能写成 `front == rear` 的陷阱，要看清定义的是哪种约定。
10. 两栈共享判满是 `top1 + 1 == top2`，不是 `top1 == top2`。
11. 后缀表达式求值时，先弹出的是**右**操作数。
12. `isp` 与 `icp` 对括号故意相反：`(` 是 1/6，`)` 是 6/1。
13. Hanoi 的移动次数 $2^n-1$ 和递归调用次数 $2^{n+1}-1$ 是同一个东西的两倍加一，别把它们当成两个量级。
14. 递归深度过大会栈溢出，转非递归要用显式栈。
15. 广义表的 `tail` 结果一定是表，`head` 可能不是。
16. 空表深度为 1，原子深度为 0。
17. 二叉树 $n_0=n_2+1$ 是**结点数**关系，不是高度关系。
18. 完全二叉树编号从 1 开始时，左子女是 $2i$；从 0 开始时是 $2i+1$，两种约定都会出现。
19. 前序 + 后序不能唯一确定二叉树。
20. 空指针域个数是 $n+1$，不是 $n$。
21. 线索化利用的正是那 $n+1$ 个空指针域。
22. 建堆 $O(n)$，堆排序 $O(n\log n)$，两者别混。
23. 大根堆用于升序排序，小根堆用于降序。
24. 霍夫曼树的 WPL 有两种算法（叶子权值×深度、内部结点权值和），要会用后者验算。
25. 霍夫曼编码不唯一，但 WPL 唯一，编码长度唯一。
26. Catalan 数同时是「出栈序列数」「二叉树形态数」，题目换个说法要认得出来。
27. 复杂度看的是最内层语句**总共**执行多少次；循环层数只是推导过程，不是判据。
28. 递归算法的时间复杂度要写递推式，不能只看循环。
29. `O(2n)` 写成 `O(n)`，别在答案里留常数。
30. 手算 `next` 时，`next[j]` 看的是 $p[0..j-1]$，**不包含** $p[j]$ 自己。

## 10. 真题分析（2011 / 2012 / 2023 / 2025）

四份卷子都完整过了一遍（题干提取在 `material/exams/`，已 gitignore）。先说结论：**题型固定、考点重复率极高、算法设计占 40%~50%**。

### 卷面结构

| 年份 | 时长 | 填空 | 问答 | 算法设计 |
|---|---|---|---|---|
| 2011 | 120 分钟 | 25% | 35% | 40% |
| 2012 | 120 分钟 | 20% | 30% | 50% |
| 2023 | 120 分钟 | 20% | 40% | 40% |

2025 那份不是空白卷，是「期中试卷讲解」课件，题型仍然是填空 + 问答 + 算法设计三块，可以当作最新一年的风向。

算法设计题每题 10~15 分，卷面明确要求「先写思路，再写 C/C++ 代码」。丢分通常不在思路，而在边界、空指针和递归出口。

### 高频考点（四份卷子里出现的次数）

出现 4 次：广义表 Head/Tail 复合求值、栈与队列的容量与假溢出、树与二叉树的转换（左孩子-右兄弟）、完全二叉树的性质与编号、KMP 的 next 与匹配过程、递归改非递归。

出现 3 次：矩阵压缩存储寻址（对称矩阵、三对角矩阵）、中缀转后缀、堆的判断与调整、哈夫曼树与编码、线索二叉树、二叉树的递归计数填空。

出现 2 次：出栈序列计数、卡特兰数（二叉树形态数）、「三类序列相同」的二叉树、完全二叉树求最近公共祖先、递归式求渐近复杂度、进制转换、非递归求最大值、由先根+后根构造森林。

可以看到，**没有一道题是「背概念就能答」的**：填空里也要手算，问答里也要画图，算法设计是纯粹的代码。

### 明确不考

四份卷子一次都没出现：**图、内部排序、查找（BST / 散列 / B 树）**。这些是期中之后的内容，现在不用碰，别被课本后面的章节分心。

### 略超纲但真考过的

- **最大子数组和**（2012 三-3）：Kadane 算法，`cur = max(x, cur + x); best = max(best, cur)`，$O(n)$。
- **最大全 1 子矩阵**（2023 三-1）：逐行累加高度，把问题转成「柱状图中最大矩形」，单调栈，$O(mn)$。
- **递归式求复杂度**（2023 二-2、2025 问答 1）：如 $T(N)=3T(N/4)+N$，用主定理，$a=3,\ b=4,\ \log_b a\approx0.79<1$，所以 $T(N)=O(N)$。
- **进制转换**（2023 三-2、2025 三-1）：除基取余，余数入栈，出栈即结果。

这四类不在课件里，但既然考过，至少要认得题型、知道思路。

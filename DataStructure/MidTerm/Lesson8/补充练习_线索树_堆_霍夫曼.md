# 一、线索二叉树

## 1.1 为什么会有空指针

n 个结点的二叉链表有 2n 个指针域，真正指向子女的只有 n−1 个（每个非根结点被父结点指一次），所以空指针有：

```
2n − (n − 1) = n + 1
```

线索化就是把这 n+1 个空指针利用起来：空的左指针存**前驱**，空的右指针存**后继**。为了区分“这是孩子”还是“这是线索”，每个结点加两个标记：

| 标记 | 含义 |
|---|---|
| `ltag = 0` | `left` 指向左子女 |
| `ltag = 1` | `left` 指向前驱线索 |
| `rtag = 0` | `right` 指向右子女 |
| `rtag = 1` | `right` 指向后继线索 |

> 注意：tag 的语义是“指针是不是线索”，不是“有没有孩子”。空指针被线索填满后，tag 一定是 1。

## 1.2 建线索：中序遍历 + 一个 pre

```cpp
void inThread(ThreadNode *p, ThreadNode *&pre) {
    if (!p) return;
    inThread(p->left, pre);

    if (!p->left) {           // p 的左空，指向前驱
        p->left = pre;
        p->ltag = 1;
    }
    if (pre && !pre->right) { // 前驱的右空，指向后继（当前 p）
        pre->right = p;
        pre->rtag = 1;
    }
    if (!p->right) p->rtag = 1;  // 最后一个结点右线索为空，但标记仍是线索
    pre = p;

    inThread(p->right, pre);
}
```

三个容易漏的点：

1. `pre` 是**引用**，否则递归回来就丢了上一个结点；
2. 先递归左子树，再处理 p，最后递归右子树——这就是中序；
3. 中序最后一个结点没有后继，`right` 保持 `NULL`，但 `rtag` 要置 1。否则“线索总数 = n+1”会少 1。上面代码里 `if (!p->right) p->rtag = 1;` 就是补这一下的。

## 1.3 找第一个、后继、前驱

| 目标 | 做法 |
|---|---|
| 中序第一个 | 从根沿左链走，直到 `ltag == 1` |
| 中序最后一个 | 从根沿右链走，直到 `rtag == 1` |
| p 的后继 | `rtag == 1` → `p->right`；否则 → **右子树的最左下结点** |
| p 的前驱 | `ltag == 1` → `p->left`；否则 → **左子树的最右下结点** |

```cpp
ThreadNode *first(ThreadNode *p) {
    while (p && p->ltag == 0 && p->left) p = p->left;
    return p;
}
ThreadNode *next(ThreadNode *p) {
    if (!p) return nullptr;
    if (p->rtag == 1) return p->right;
    return first(p->right);
}
```

有了 `first + next`，中序遍历变成一条 for 循环，**不用栈、不用递归**：

```cpp
for (ThreadNode *p = first(root); p; p = next(p))
    visit(p);
```

## 1.4 拿样例走一遍

树由前序 `ABHFDECKG`、中序 `HBDFAEKCG` 建成。中序序列是：

```
H  B  D  F  A  E  K  C  G
```

逐点写出前驱/后继：

| 结点 | 前驱 | 后继 |
|---|---|---|
| H | — | B |
| B | H | D |
| D | B | F |
| F | D | A |
| A | F | E |
| E | A | K |
| K | E | C |
| C | K | G |
| G | C | — |

重点检查两个“不是直接取子女”的位置：

- **B 的后继是 D**：B 有右子树，后继是右子树最左下结点。这棵树里 B 的右子女是 F，F 的左子女是 D，所以最左下结点是 D。
- **C 的后继是 G**：C 有右子树，右子女 G 没有左孩子，所以是 G。

线索总数应为 `n+1 = 10`。实测 `log/threaded.txt` 第 6 行就是 10。

## 1.5 易错点

1. `ltag = 0` 表示“指向真子女”，不要反过来记。
2. 有右子树时，后继不是 `p->right`，而是右子树的**最左下**结点。
3. 统计线索时只递归真子女，不能顺着线索走，否则会绕圈。
4. 中序最后结点的 `rtag` 要置 1（右指针仍为空），否则线索数少 1。
5. 后序线索找后继可能需要父指针，所以考试默认考中序线索。

# 二、堆

## 2.1 堆就是“数组里的完全二叉树”

因为是完全二叉树，父子关系直接由下标算：

| 约定 | 父 | 左子女 | 右子女 | 最后一个非叶 |
|---|---|---|---|---|
| 0 基 | `(i-1)/2` | `2i+1` | `2i+2` | `(n-2)/2` |
| 1 基 | `i/2` | `2i` | `2i+1` | `n/2` |

最小堆满足 `a[i] <= a[2i+1]` 且 `a[i] <= a[2i+2]`；最大堆反过来。注意：**堆只保证父子有序，不保证兄弟或整棵树有序**。

## 2.2 两个动作

**SiftUp（上浮）**：新元素放末尾，比父小就往上换。用于插入。

```cpp
void siftUpMin(int *a, int j) {
    int temp = a[j];
    while (j > 0 && temp < a[(j - 1) / 2]) {
        a[j] = a[(j - 1) / 2];
        j = (j - 1) / 2;
    }
    a[j] = temp;
}
```

**SiftDown（下沉）**：和**较小**的子女交换，一路沉到底。用于删除堆顶和建堆。

```cpp
void siftDownMin(int *a, int i, int n) {
    int temp = a[i];
    int j = 2 * i + 1;
    while (j < n) {
        if (j + 1 < n && a[j + 1] < a[j]) ++j;  // 选较小的子女
        if (temp <= a[j]) break;
        a[i] = a[j];
        i = j;
        j = 2 * i + 1;
    }
    a[i] = temp;
}
```

> 旁注｜“先暂存 temp，一路把子女往上挪，最后再填回”比“每次交换”少一半赋值。考试写交换版也不扣分，但代码题里更推荐这一版。

## 2.3 建堆为什么是 O(n)

从最后一个非叶结点往前倒着 SiftDown。直觉上每个结点 O(log n)，但**越靠下的结点越多，它们能沉的距离越短**：

- 高度为 h 的结点约有 `n / 2^(h+1)` 个；
- 每个最多沉 h 层；
- 总代价 `Σ h · n / 2^(h+1) = O(n)`。

所以建堆是 **O(n)**，堆排序才是 **O(n log n)**。这两个别混。

## 2.4 插入、删除、堆排序

| 操作 | 做法 | 复杂度 |
|---|---|---|
| 插入 | 放末尾 → SiftUp | O(log n) |
| 删除堆顶 | 末尾搬到堆顶 → 堆大小减 1 → SiftDown | O(log n) |
| 建堆 | 从 `(n-2)/2` 倒着 SiftDown | O(n) |
| 堆排序 | 建最大堆 → 反复“堆顶换末尾 + 对堆顶 SiftDown” | O(n log n) |

删除堆顶的关键顺序：

```cpp
int deleteMin(int *a, int &n) {
    int top = a[0];
    a[0] = a[--n];          // 先减 n，再搬
    siftDownMin(a, 0, n);   // 待调整范围已经排除末尾
    return top;
}
```

如果先 `siftDown` 再减 n，已排好的末尾会被重新搅进堆里。

## 2.5 手算两组

**建堆**：`{53, 17, 78, 9, 45, 65, 87, 23}`

从 `(8-2)/2 = 3` 开始：

| i | 调整后数组 |
|---|---|
| 3 | 53 17 78 9 45 65 87 23（9 比 23 小，不动） |
| 2 | 53 17 65 9 45 78 87 23 |
| 1 | 53 9 65 17 45 78 87 23 |
| 0 | 9 17 65 23 45 78 87 53 |

最终 `9 17 65 23 45 78 87 53`，满足最小堆。

**插入**：依次插入 `4, 2, 5, 8, 3, 6, 10, 14`，最终数组：

```
2 3 5 8 4 6 10 14
```

连续删除堆顶，得到升序：

```
2 3 4 5 6 8 10 14
```

## 2.6 判堆

只要检查每个结点和它的真子女：

```cpp
bool isMinHeap(const int *a, int n) {
    for (int i = 0; i < n; ++i) {
        int l = 2 * i + 1, r = 2 * i + 2;
        if (l < n && a[l] < a[i]) return false;
        if (r < n && a[r] < a[i]) return false;
    }
    return true;
}
```

`9 17 23 45 53 65 78 87` 是最小堆；把末尾改成 5 就不是。

## 2.7 易错点

1. 建堆从 `(n-2)/2` 开始，不是 `n/2`（0 基）；1 基才是 `n/2`。
2. 建堆 O(n)，堆排序 O(n log n)。
3. 删除堆顶后，待调整范围要减 1。
4. 大根堆排升序，小根堆排降序。
5. 堆只保证父子关系，**层序数组不一定是整体有序的**。
6. 判堆时只检查真子女，越界的下标不能读。

# 三、霍夫曼树与编码

## 3.1 构造：每次合并最小的两个

1. 每个权值建一棵单结点树，放进森林；
2. 反复取**根权值最小**的两棵树，合并成新树，根权值为二者之和；
3. 新树放回森林，直到只剩一棵。

权值越大，离根越近，编码越短。

## 3.2 WPL 的两种算法

```
WPL = Σ (叶子权值 × 叶子深度)
```

也可以边合并边累加：**WPL 等于所有内部结点权值之和**。第二种不用逐叶求深度，手算和验算都更快。

## 3.3 用 `{15, 3, 14, 2, 6, 9, 16, 17}` 走一遍

按字符 `A..H` 对应上面的权值。合并顺序：

```
2 + 3   = 5
5 + 6   = 11
9 + 11  = 20
14 + 15 = 29
16 + 17 = 33
20 + 29 = 49
33 + 49 = 82
```

WPL = 5 + 11 + 20 + 29 + 33 + 49 + 82 = **229**。

生成编码时约定**左 0、右 1**（程序把较小的根放左边）：

| 字符 | 权值 | 编码 | 长度 | 贡献 |
|---|---|---|---|---|
| A | 15 | 111 | 3 | 45 |
| B | 3 | 10101 | 5 | 15 |
| C | 14 | 110 | 3 | 42 |
| D | 2 | 10100 | 5 | 10 |
| E | 6 | 1011 | 4 | 24 |
| F | 9 | 100 | 3 | 27 |
| G | 16 | 00 | 2 | 32 |
| H | 17 | 01 | 2 | 34 |

合计 229。编码不唯一：合并时左右互换，只会让 0/1 对调，WPL 和码长不变。

## 3.4 解码与前缀性质

解码从根出发：读 `0` 走左，读 `1` 走右；到叶子输出字符，再回到根。例如：

```
原文：ABCDEFGH
编码：111 10101 110 10100 1011 100 00 01
    = 111101011101010010111000001（27 位）
```

**无前缀码**：没有任何一个编码是另一个编码的前缀。原因是“字符只放在叶结点”——如果字符放在内部结点，那么走到该结点就输出了，继续往下读必然产生歧义。

前缀校验就是两两比较：短串是否是长串的前缀。

## 3.5 易错点

1. WPL 是“叶权 × 叶深度”，不是“结点权 × 层数”。
2. 霍夫曼树没有度为 1 的结点；n 个叶子共 2n−1 个结点。
3. 编码不唯一，但 WPL 唯一、码长唯一。
4. 前缀性质来自“字符只在叶子”，不是来自“编码长度不同”。
5. 用内部结点权值和验算 WPL，能快速发现合并顺序算错。

# 五、自测（附答案）

**题 1** 5 个结点、8 个结点的不同二叉树形态各有多少棵？

<details><summary>答案</summary>

Catalan 数：`b5 = 42`，`b8 = 1430`。

</details>

**题 2** 中序线索树中，结点 p 有右子树，它的中序后继是谁？

<details><summary>答案</summary>

右子树的**最左下结点**：从 `p->right` 出发，沿左链一直走到 `ltag == 1` 的结点。

</details>

**题 3** 向最小堆 `{4, 5, 8, 14, 6, 10}` 插入 3，画出插入后的数组。

<details><summary>答案</summary>

`3 5 4 14 6 10 8`。

过程：3 放到末尾（下标 6），与父 `a[2]=8` 交换；再与父 `a[0]=4` 交换，停在根。

</details>

**题 4** 权值 `{15, 3, 14, 2, 6, 9, 16, 17}` 建霍夫曼树，WPL 是多少？

<details><summary>答案</summary>

229。内部结点和：5 + 11 + 20 + 29 + 33 + 49 + 82 = 229。

</details>

**题 5** 为什么霍夫曼编码不需要分隔符就能解码？

<details><summary>答案</summary>

因为它是前缀码：没有任何一个编码是另一个编码的前缀，且所有字符都在叶结点。从左往右走树，一旦到达叶子就唯一确定一个字符，不会和更长的编码混淆。

</details>

# 六、一句话带走

线索化把“空指针”变成“下一步”，堆把“完全二叉树”变成“数组”，霍夫曼把“频度”变成“深度”——三者都是拿结构里浪费掉的信息，换时间或空间。

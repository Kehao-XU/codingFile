# 学案 05 · 栈和队列

对应课件 `课件/chapter-4-full.pptx`（80 页）｜教材：殷人昆《数据结构》第 3 版，第 4 章

线性表允许在任意位置增删；把位置限制成"只在一端"或"一端进另一端出"，就得到两种全程 O(1) 的结构。本讲的重点不在结构本身（它们太简单），而在**用它们改写计算的顺序**：递归、括号、表达式、迷宫，本质都是"后进先出"或"先进先出"。

---

## 一、栈

**栈**：只允许在一端插入和删除的线性表。允许操作的一端叫**栈顶**（top），另一端叫**栈底**。特性：后进先出（LIFO）。

抽象数据类型（接口）：

```
Push(x)     进栈
Pop(x)      出栈，x 带回被删元素
GetTop(x)   取栈顶元素，不删
MakeEmpty() 置空
IsEmpty() / IsFull() / GetSize()
```

### 1.1 顺序栈

用数组 `elements[maxSize]` 存元素，`top` 是栈顶元素的**下标**（不是指针）：

| 状态 | 判定 |
|---|---|
| 空栈 | top == -1 |
| 满栈 | top == maxSize - 1 |
| 元素个数 | top + 1 |

```cpp
void push(int x)  { elements[++top] = x; }      // 先加下标，再放
bool pop(int &x)  { if (top == -1) return false;
                    x = elements[top--]; return true; }
```

先判满/判空是必须的：满时进栈叫**上溢**，空时出栈叫**下溢**。下溢不是错误，是算法该结束的信号。

### 1.2 两个栈共享一片空间

两个栈各占一半，可能一个满了另一个还空着。让它们从两端向中间长，就能互相调剂：数组 `space[maxSize]`，第 0 个栈的栈顶 `t[0]` 从 -1 往右走，第 1 个栈的栈顶 `t[1]` 从 maxSize 往左走。

| 状态 | 判定 |
|---|---|
| 栈 0 空 | t[0] == -1 |
| 栈 1 空 | t[1] == maxSize |
| 共享区满 | t[0] + 1 == t[1]（两个栈顶相邻） |

满的条件是"两个栈顶只差一格"，不是"两个栈顶相等"——它们相向而行，相邻就说明中间已经没位置了。

> 旁注｜课件还讲了 **n 个栈共享一个数组**（栈浮动技术）：初始每个栈分 m/n 的空间，某个栈满了就把邻居整体挪一段，腾出空隙。移动代价高，实际系统里很少用，理解"为什么需要移动"即可。

### 1.3 链式栈

栈顶放在链头，`push` 就是头插，`pop` 就是删头结点，都是 O(1)。链式栈没有"栈满"问题（除非内存耗尽），适合元素个数不确定或多栈并存的场合。

## 二、栈的应用

### 2.1 括号匹配

从左向右扫描：遇左括号进栈，遇右括号就看栈顶是不是与之配对的左括号，是则弹出，否则不匹配；扫完栈必须为空。

正确性来自一条观察：每个右括号总是与**最近遇到的未匹配**的左括号配对——这正是后进先出。

### 2.2 三种表达式

| 记法 | 形式 | 例子（A+B*C） |
|---|---|---|
| 中缀 | 操作数 运算符 操作数 | A+B*C |
| 前缀 | 运算符 操作数 操作数 | +A*BC |
| 后缀 | 操作数 操作数 运算符 | ABC*+ |

中缀要靠优先级和括号才能定序；后缀把顺序直接编进了位置里，所以**不需要括号、不需要优先级表**，从左往右扫一遍即可。

**后缀求值**：扫表达式，遇操作数进栈；遇运算符连续出栈两个数，先出的是右操作数 y、后出的是左操作数 x，计算 x op y，结果再进栈。扫完栈顶就是答案。

顺序不能反：`A B -` 是 A-B，不是 B-A。这一点在代码里表现为 `y = pop(); x = pop(); push(x - y);`。

**中缀转后缀**：用运算符栈，靠**栈内优先级 isp**（in-stack priority）和**栈外优先级 icp**（in-coming priority）决定动作：

| 运算符 | `;` | `(` | `*` `/` | `+` `-` | `)` |
|---|---|---|---|---|---|
| isp（栈内） | 0 | 1 | 5 | 3 | 6 |
| icp（栈外） | 0 | 6 | 4 | 2 | 1 |

规则：读入 ch，与栈顶 op 比较

- `icp(ch) > isp(op)`：ch 进栈
- `icp(ch) < isp(op)`：op 出栈并输出
- `icp(ch) == isp(op)`：出栈但不输出（这只发生在 `(` 与 `)` 配对时），然后读下一字符

同一运算符在栈内、栈外的优先级不同，是为了让"左结合"落地：栈内的 `+`（3）比栈外新来的 `+`（2）高，所以新来的 `+` 会逼着旧的 `+` 先出栈——先算左边。

**中缀直接求值**：两个栈，`OPTR` 放运算符、`OPND` 放操作数，规则同上，只是 `icp(ch) < isp(op)` 时不是输出，而是弹出一个运算符和两个操作数、算完再压回 `OPND`。

### 2.3 迷宫

用栈保存走过的路径，每个元素是三元组 `(x, y, d)`：在 (x, y) 处沿第 d 个方向走到下一格。走到死路就弹栈回溯，换一个方向；另外开一个 `mark` 数组记录已走过的格子，防止绕圈。栈空即无解。

> 旁注｜迷宫还有一条路是递归（第 6 讲）或 BFS（图那一章）。三者的区别：栈 = 深度优先，队列 = 广度优先，递归 = 用系统栈做深度优先。

## 三、队列

**队列**：只允许在一端删除、另一端插入的线性表。删除端叫**队头**（front），插入端叫**队尾**（rear）。特性：先进先出（FIFO）。

### 3.1 顺序队列与假溢出

进队让 `rear` 加 1 再写入，出队让 `front` 加 1 再取值。问题出在：`rear` 一路向右，即使前面出队腾出了空位，`rear == size-1` 时仍然进不了队——这叫**假溢出**。

### 3.2 循环队列

把数组首尾相接，指针加 1 变成取模：

```
front = (front + 1) % size
rear  = (rear + 1) % size
```

| 状态 | 判定 |
|---|---|
| 初始化 | front == rear == 0 |
| 空 | front == rear |
| 满 | (rear + 1) % size == front |

满和空都是 `front == rear`，所以**牺牲一个存储单元**来区分：数组开 size 个位置，最多只存 size-1 个元素。另一种办法是加一个 `tag` 标记最近一次操作是进队还是出队，这样能用满全部空间，但每次操作多一次判断，频繁使用的队列一般不这么做。

元素个数：`(rear - front + size) % size`。

### 3.3 链式队列

队头在链头、队尾在链尾，设 `front`、`rear` 两个指针。空队列 `front == NULL`；进队时若队列为空，新结点既是头也是尾。链式队列没有队满问题，只有队空问题。

### 3.4 应用与变型

- **杨辉三角**：用队列逐行生成。每行开头塞一个 0 当分隔，出队两个相邻数相加再入队，就得到下一行。
- **打印缓冲区**：主机写、打印机读，先来先打，用队列。这类"生产者-消费者"缓冲是队列最典型的工程用例。
- **双端队列**：两端都能插删。固定一端只进不出就是栈；一端只删、另一端只插，就是"限制输入/输出的双端队列"。
- **优先级队列**：每次让优先级最高的元素出队，同优先级按到达顺序。课件用有序数组实现：进队时从后往前找位置插入，O(n)；出队取 0 号元素后整体前移，O(n)。

## 五、易错点

1. 后缀求值时先弹出的是**右**操作数。写成 `x - y` 还是 `y - x`，取决于你把第一次 pop 赋给谁，写完必须手算一遍 `A B -`。
2. `icp` 与 `isp` 相等只在括号配对时出现。若代码里对 `+` 也走了"相等"分支，说明表背错了。
3. 循环队列判满用 `(rear+1)%size == front`，别忘了取模；直接写 `rear+1 == front` 在绕回后会失效。
4. 两个栈共享空间时判满是 `t[0]+1 == t[1]`，不是 `t[0] == t[1]`。
5. 顺序栈的 `top` 是下标，空栈是 -1；链式栈的 `top` 是指针，空栈是 NULL。两套代码别混。
6. 括号匹配结束时必须检查栈空：`(()` 扫完栈里还剩一个左括号，不检查就会误判为匹配。

## 七、一句话带走

栈把"最近的未完成事项"顶到最前面，队列把"最早到达的事项"排到最前面；表达式求值和 BFS 都是这两种顺序的直接后果。
